# 01 Navigation

- Breadcrumbs (breadcrumbs.jpg): Breadcrumb trails are constructed using 14px text, separated by a / delimiter with approximately 4px–6px of horizontal padding on either side. Parent pages use a muted, secondary text color, while the current page context is bolded or uses a primary text color to establish clear hierarchy without requiring background containers.  
- Collapsed Sidebar (collapsed_sidebar.jpg): A dense, collapsed sidebar should be fixed at a narrow width (approx. 60px–64px). Navigation relies purely on center-aligned, 16px–20px icons. Active states are communicated through a subtle, low-opacity background fill and high-contrast icon colors, rather than borders or scaling.
- Expanded Sidebar (expanded_sidebar.png): The expanded state anchors at around 240px wide. List items maintain a tight 28px–32px height to allow high density. The layout relies on a strict grid: a 16px icon, an 8px gap, and 13px text. Section headers are purely typographical (all-caps or slightly bolder) with no dividing lines, using negative space to group items. 
- Command Palette (mid_search.png): The mid-search modal is exactly centered, capped at approximately 600px–640px wide to maintain readability. Depth is created mechanically: the background UI is dimmed with a dark overlay (e.g., 40%–50% black), and the palette itself features a solid structural background with a heavy drop shadow (e.g., 40px blur) to guarantee it sits atop the z-index stack.  
- Dropdown menu with shortcuts (menu_with_shortcuts.png) enforce strict alignment to balance readability with user education. Menu items maintain a dense 32px height with the primary action label left-aligned in standard 13px text. To subtly educate users on the keyboard shortcuts they could have used, the shortcut keys are flush right-aligned against the edge of the menu container. Crucially, these shortcuts use significantly reduced visual weight—typically a smaller 11px–12px font size and a muted, low-contrast text color—ensuring they remain discoverable without competing visually with the primary navigation labels
