## Code review findings to action

- **`components/ui/button.tsx`** — `onClick` stays in the `...props` spread, so `onClick={loading ? undefined : props.onClick}` is immediately overwritten by the spread that follows. Currently masked by `pointer-events-none` + `aria-disabled`, so it isn't a live bug, but it's fragile. Fix: destructure `onClick` explicitly.
- **`lib/cn.ts`** — reviewer suggests adding `bg-color` and `border-color` class-group overrides. **Verify this before applying**: the original bug was real because `text-ui-base` (size) and `text-on-accent` (colour) are both `text-*` and genuinely collide. `bg-*` and `border-*` have no size/colour ambiguity, so tailwind-merge's defaults may already handle them. Write a failing test first; if none can be written, the finding is over-generalized.
